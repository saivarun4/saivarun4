# Sai Varun Chandrashekar

**AI/ML Researcher | AI Safety & Alignment · Interpretability for LLM Agents · Trustworthy AI**

As an aspiring AI/ML researcher, the question driving my research is how decision representations in LLM agents can be made interpretable by construction, so that each explanation is faithful to the computation behind the decision and the agent stays robust.

## AI/ML Projects & Repositories

- **[AirSense-X: Explainability-Augmented Physics-Informed Neural Network for Air Quality Index Forecasting](https://github.com/saivarun4/AirSense-X-Interpretable-Physics-Informed-Neural-Networks-for-Forecasting-Air-Quality-Index-AQI-)**  
  Physics-informed and explainable neural forecasting of the Air Quality Index using pollutant dynamics.  
  **Key tools:** `PyTorch` · `DeepXDE` · `SHAP` · `LIME`
- **[Explainability-Augmented Generative Adversarial Networks for Air Quality Index Classification](https://github.com/saivarun4/Explainability-Augmented-Generative-Adversarial-Networks-for-AQI-Classification)**  
  GAN-based multi-class AQI classification with synthetic data generation for class imbalance and post-hoc model explanations.  
  **Key tools:** `PyTorch` · `TensorFlow` · `SHAP` · `LIME`
- **[GATED: Knowledge-Distilled Ultra-Lightweight Neural Network for Intelligent EV Battery Diagnostics](https://github.com/saivarun4/Implementation-Notebook---GATED-Approach)**  
  Gating-based knowledge distillation transfers domain-specific teacher knowledge to a compact neural network for EV battery diagnostics.  
  **Key tools:** `PyTorch` · `Ensemble learning` · `Knowledge distillation`
- **[ICNN: Explainability-Augmented CNN for Alzheimer's Disease Stage Classification](https://github.com/saivarun4/Code-Repository---Explainability-Augmented-CNN-for-Alzheimer-s-Disease-Stage-Classification)**  
  Four-class alzheimer's disease stage classification with post-hoc explanations to interpret predictions and identify disease-associated features in brain MRI.  
  **Key tools:** `TensorFlow` · `SHAP` · `LIME` · `OpenCV`
